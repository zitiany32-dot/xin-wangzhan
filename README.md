# TIANCONG — Immersive Industrial Website

Awwwards-style immersive single-page website for **Handan Tiancong Fastener Manufacturing Co., Ltd.** (est. 1989, Yongnian · Handan · China).

## Style
Dark "molten forge" industrial aesthetic inspired by award-winning 3D web experiences (Three.js + GSAP ScrollTrigger + Lenis smooth scroll):

- **WebGL hero** — procedural 3D hex bolt with metallic PBR materials, floating hex nuts, 900-particle spark field, mouse parallax + scroll-driven camera
- **Scroll storytelling** — pinned horizontal-scroll manufacturing process (6 stations), animated counters, reveal choreography
- **Industrial details** — film-grain noise overlay, custom cursor, marquee strips, molten-orange/amber on near-black

## Content
Factory content adapted from the Tiancong corporate site: capability matrix, global ports & sailing times, project track record, ordering steps, FAQ, WhatsApp CTA.

## Stack
Pure static — no build step. Three.js 0.160 + GSAP 3.12 + Lenis via CDN.

## Deploy (free)
Any static host works:
- **Vercel**: import this repo → deploy (free `*.vercel.app` domain)
- **GitHub Pages**: Settings → Pages → Deploy from branch `main` (free `*.github.io` domain)
- **Cloudflare Pages**: connect repo → deploy
